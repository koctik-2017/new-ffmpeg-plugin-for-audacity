# new-ffmpeg-plugin-for-audacity
Новый ffmpeg плагин для audacity, плагин собран по образцу плагина от Buanzo из исходников с сайта ffmpeg.org на основе версии 8.1 с добавлением коммита для поддержки декодирования HE-AAC 960 (DAB+)
Сборка производилось при помощи подсказок ИИ Claude с использованием Visual Studio и MINGW
Сборка проверена на работоспособность, однако если что-то не работает то пишите об этом в Issues и я постараюсь это исправить
Для корректной работы плагина распакуйте dll из архива в папку где установлена audacity (не забывайте что сборка x86 не будет работать с audacity x64, а сборка x64 не будет работать с audacity x86)
