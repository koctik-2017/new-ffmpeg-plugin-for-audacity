# new-ffmpeg-plugin-for-audacity инструкция по сборке
__Для сборки вам понадобится:__
1. Windows 10 x64 1809 или выше (на более ранних версиях возможность сборки не тестировалась и поэтому не гарантируется)
2. Visual Studio Community (в установщике выбираем «Разработка классических приложений на C++» а так-же выбираем MSVC v14.51 или новее для x64/x86, Пакет SDK для Windows 11, MSVC Build Tools v14.51 или выше для ARM64/ARM64EC (именно v14.51 или выше а не v143!), все остальное (ATL, MFC, профилирование, Build Insights, CMake, IntelliCode, ASan, vcpkg, JIT-отладчик, Copilot, тест-адаптеры) выключаем, оно нам не нужно.)
3. Git for Windows SDK, скачать его можно из репозитория https://github.com/git-for-windows/build-extra/releases (для установки может потребоваться VPN)
Переменная **MSYS2_PATH_TYPE=inherit** (данную переменную нужно прописать в список системных переменных, чтобы работало из любого окна)
4. Файлы **build-ffmpeg.sh** и **vcvarsamd64_arm64.bat** (**build-ffmpeg.sh** положите в **%USERPROFILE%** а **vcvarsamd64_arm64.bat** положите в **C:\Program Files\Microsoft Visual Studio\18\Community\VC\Auxiliary\Build**)

__После того как вы подготовили инструменты для сборки переходим к настройке рабочей среды:__
1. Создаем ярлык с названием **x64 Native Tools Command Prompt for VS** (путь **%comspec% /k "C:\Program Files\Microsoft Visual Studio\18\Community\VC\Auxiliary\Build\vcvars64.bat" && mingw64.exe && exit**, рабочая папка **"C:\Program Files\Microsoft Visual Studio\18\Community\"**)
2. Создаем ярлык с названием **x64_x86 Cross Tools Command Prompt for VS** (путь **%comspec% /k "C:\Program Files\Microsoft Visual Studio\18\Community\VC\Auxiliary\Build\vcvarsamd64_x86.bat" && mingw32.exe && exit**, рабочая папка **"C:\Program Files\Microsoft Visual Studio\18\Community\"**)
3. Создаем ярлык с названием **x64_arm64 Cross Tools Command Prompt for VS** (путь **%comspec% /k "C:\Program Files\Microsoft Visual Studio\18\Community\VC\Auxiliary\Build\vcvarsamd64_arm64.bat" && mingw64.exe && exit**, рабочая папка **"C:\Program Files\Microsoft Visual Studio\18\Community\"**)
4. Запускаем ярлык **x64 Native Tools Command Prompt for VS** и в открывшемся окне вводим **pacman -S mingw-w64-x86_64-toolchain mingw-w64-x86_64-nasm mingw-w64-x86_64-pkg-config git make diffutils**
5. Запускаем ярлык **x64_x86 Cross Tools Command Prompt for VS** и в открывшемся окне вводим **pacman -S mingw-w64-i686-toolchain mingw-w64-i686-nasm mingw-w64-i686-pkg-config**
6. После того как инструменты загрузятся выполняем команду **cd / && git clone https://github.com/FFmpeg/FFmpeg.git ffmpeg**
7. После того как исходники загрузились выполняем команду **git checkout n9.1** (если нужна другая версия, например **n8.1** то вместо **n9.1** вводим **n8.1**)
8. Закрываем окна которые открылись по ярлыку, а затем запускаем нужный ярлык для сборки под нужную архитектуру (например для x64 надо запустить ярлык **x64 Native Tools Command Prompt for VS**, для x86 надо запустить **x64_x86 Cross Tools Command Prompt for VS**, ну а для arm64 запускаем **x64_arm64 Cross Tools Command Prompt for VS**)
9. В открывшемся окне вводим **bash ~/build-ffmpeg.sh**, вводим цифру для начала сборки под нужную архитектуру (цифру вводим ту которая соответствует запущенному ярлыку, например если вы запустили **x64 Native Tools Command Prompt for VS** то вводим 1, а если запустили **x64_x86 Cross Tools Command Prompt for VS** то вводим 2) и нажимаем Enter (не пытайтесь одновременно запустить сборку для двух разных архитектур, например для x64 и arm64, иначе вы получите ошибку)
10. Готовые .dll после того как сборка завершится вы сможете найти по пути **C:\git-sdk-64\mingw64\ffmpeg-build-msvc-x64\bin** (для версии x64) либо по пути **C:\git-sdk-64\mingw64\ffmpeg-build-msvc-arm64\bin** (для arm64) ну или по пути **C:\git-sdk-64\mingw32\ffmpeg-build-msvc-x86\bin** (для x86 версии)
11. Готовые .dll скопируйте в папку где находится audacity (например **C:\Program Files\Audacity**) и проверьте в настройках audacity отображается ли версия ffmpeg, если да то вы все сделали правильно, если нет то это значит что либо архитектура .dll и audacity (например для audacity x64 нужны .dll собранные под x64) отличается, либо выбранная вами версия ffmpeg еще не поддерживается в audacity (в этом случае надо ждать пока разработчики audacity добавят поддержку этой версии)
